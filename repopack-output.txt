## 1. ההבדל בין `a` לבין `Link`
- **`a`**: הדפדפן טוען את כל הדף מחדש מהשרת, וכל ה-state נמחק.
- **`Link`**: המעבר קורה בתוך האפליקציה בלי טעינה מחדש. רק הקומפוננטה המתאימה מתחלפת, וה-state נשמר.

## 2. המשמעות של `:id` בנתיב `"recipes/:id"`
`:id` הוא פרמטר בכתובת. הנקודתיים אומרות שבמקום הזה יכול להופיע כל ערך, כך ש-`/recipes/5` וגם `/recipes/12` מתאימים לנתיב. בתוך הקומפוננטה מגיעים לערך עם `useParams`:
`const { id } = useParams();`

## 3. למה `id` מ-`useParams` הוא מחרוזת, ואיזו בעיה זה יוצר
כל מה שנמצא בכתובת הוא טקסט, ולכן הערך מגיע כמחרוזת. כשמוסיפים לו 1 מתקבל חיבור של מחרוזות: `"1" + 1` נותן `"11"` ולא 2. הפתרון הוא להמיר למספר לפני החישוב: `Number(id) + 1`.

## 4. למה ב-`useEffect` של עמוד הפרטים כתבנו `[id]` ולא `[]`
עם `[id]` ה-effect רץ מחדש בכל פעם ש-`id` משתנה. עם `[]` הוא רץ רק פעם אחת, כשהקומפוננטה נטענת. אילו כתבנו `[]`, לחיצה על "המתכון הבא" הייתה משנה את הכתובת, אבל המתכון הקודם היה נשאר על המסך, כי הקומפוננטה לא נוצרת מחדש וה-fetch לא רץ שוב.

## 5. למה ברשימה משתמשים ב-`data.recipes` ובפרטים ב-`data`
- `/recipes` מחזיר אובייקט שהמערך נמצא בתוך המאפיין `recipes` שלו, יחד עם `total`, `skip` ו-`limit`.
- `/recipes/1` מחזיר ישירות את אובייקט המתכון עצמו.

## 6. היתרון בשמירת מילת החיפוש בכתובת (`useSearchParams`)
החיפוש נשמר גם אחרי רענון הדף, אפשר לשלוח את הקישור למישהו אחר והוא יראה את אותן תוצאות, וכפתורי "אחורה" ו"קדימה" עובדים. עם `useState` הערך נמחק ברענון.
**דוגמה:** שולחים לחברה קישור ל-`/recipes?q=pizza`, והיא רואה מיד רק מתכוני פיצה.

## 7. מה עושה `replace: true`, ולמה השתמשנו בו בחיפוש
`replace: true` **מחליף** את הכתובת הנוכחית בהיסטוריה של הדפדפן במקום להוסיף כתובת חדשה. בלי זה, כל הקשה במקלדת הייתה נשמרת כרשומה נפרדת בהיסטוריה, וכפתור "אחורה" היה מוחק אות אחת בכל לחיצה. כך "אחורה" מחזיר לעמוד הקודם.

## 8. למה לא עובדים ישירות על `main`, ומה תפקיד ה-Review
`main` הוא הגרסה היציבה והמשותפת, והוא צריך לעבוד תמיד. כל אחד עובד בענף משלו, והשינויים עוברים ל-`main` רק דרך Pull Request. ה-Review הוא בדיקה של השותף לפני המיזוג: הוא מוצא טעויות, משפר את הקוד ומשתף ידע. שינוי לא נכנס ל-`main` בלי אישור.

## 9. מה גרם להתנגשות, ואיך פתרנו אותה
**הסיבה:** כולנו הוספנו שורות **באותו מקום** בקובץ `App.jsx` (ה-import וה-Route), ולכן גיט לא יכול להחליט לבד איזו גרסה נכונה.

**משמעות הסימנים:**

## 10. (בונוס) `Link` לעומת `useNavigate`
- **`Link`**: קישור שהמשתמש לוחץ עליו.
- **`useNavigate`**: מעבר מתוך הקוד, אחרי פעולה מסוימת. למשל אחרי שליחת טופס או מחיקה.
- `navigate(-1)` חוזר צעד אחד אחורה בהיסטוריה, כמו כפתור "אחורה". הוא חוזר לאן שהמשתמש היה קודם.
- `navigate("/recipes")` עובר תמיד לכתובת קבועה, ומוסיף רשומה חדשה להיסטוריה.

## 11. (בונוס) Fork לעומת Clone, ו-`origin` לעומת `upstream`
- **Fork**: עותק של ריפו של מישהו אחר, **בחשבון GitHub שלי**. העותק נמצא בשרת.
- **Clone**: הורדה של ריפו **למחשב שלי**.
- **`origin`**: הריפו שממנו שכפלתי, בדרך כלל ה-Fork שלי. לשם אני דוחף שינויים.
- **`upstream`**: הריפו המקורי שממנו עשיתי Fork. ממנו מושכים עדכונים.

import { useEffect, useState } from "react";

export default function About() {
  const [total, setTotal] = useState(null);
  const [error, setError] = useState("");

  useEffect(() => {
    fetch("https://dummyjson.com/recipes?limit=1")
      .then((res) => {
        if (!res.ok) throw new Error("שגיאה בטעינת מספר המתכונים");
        return res.json();
      })
      .then((data) => setTotal(data.total))
      .catch((err) => setError(err.message));
  }, []);

  return (
    <div>
      <h1>אודות</h1>
      <p>אפליקציית המתכונים נבנתה בכיתה, בעבודה בזוגות.</p>
      <p>המידע מגיע מהאתר dummyjson.</p>
      {error && <p>{error}</p>}
      {total !== null && <p>מספר המתכונים באתר: {total}</p>}
    </div>
  );
}

import { useState, useEffect } from "react";
import { useParams } from "react-router";
import { Link } from "react-router";

export default function RecipeDetails() {
  const { id } = useParams();
  
  const [recipe, setRecipe] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    setLoading(true);
    setError("");

    fetch(`https://dummyjson.com/recipes/${id}`)
      .then((res) => {
        if (!res.ok) throw new Error("המתכון לא נמצא");
        return res.json();
      })
      .then((data) => {
        setRecipe(data);
      })
      .catch((err) => {
        setError(err.message);
      })
      .finally(() => {
        setLoading(false);
      });
  }, [id]);

  if (loading) {
    return <p>טוען...</p>;
  }

  if (error) {
    return <p>{error}</p>;
  }

  return (
    <div>
      <p>
        <Link to="/recipes">חזרה לרשימה </Link>
      </p>

      {recipe && (
        <>
          <h1>{recipe.name}</h1>
          <p>
            זמן הכנה: {recipe.prepTimeMinutes} דקות | זמן בישול: {recipe.cookTimeMinutes} דקות | 
            מנות: {recipe.servings} | רמת קושי: {recipe.difficulty}
          </p>
          <img src={recipe.image} alt={recipe.name} width="300" />
          
          <h3>מצרכים</h3>
          <ul>
            {recipe.ingredients.map((ingredient, index) => (
              <li key={index}>{ingredient}</li>
            ))}
          </ul>

          <h3>הוראות הכנה</h3>
          <ol>
            {recipe.instructions.map((step, index) => (
              <li key={index}>{step}</li>
            ))}
          </ol>

          <div style={{ marginTop: "20px" }}>
            <Link to={`/recipes/${Number(id) + 1}`}>למתכון הבא</Link>
          </div>
        </>
      )}
    </div>
  );
}

import { Link, useSearchParams } from "react-router";
import axios from "axios";
import { useEffect, useRef, useState } from "react";

const RecipesList = () => {
    const [recipes, setRecipes] = useState([]);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState("");
    const searchRef = useRef(null)
    const [searchParams, setSearchParams] = useSearchParams();
    const search = searchParams.get("q") || "";
    const handleSearch = (e) => {
        const value = e.target.value;
        setSearchParams({ q: value }, { replace: true })
    }
    useEffect(()=>{
        searchRef.current.focus();
    },[])
    useEffect(() => {
        const conectDb = async () => {
            try {
                const { data } = await axios.get("https://dummyjson.com/recipes");
                setRecipes(data.recipes);
            }
            catch (err) {
                setError(err.message);
            }
            finally {
                setLoading(false);
            }
        }
        conectDb();
    }, [])
    const lowerSearch = search.toLowerCase();
    const filtered = recipes.filter(r => r.name.toLowerCase().includes(lowerSearch));
    return <div>
        <h1>מתכונים</h1>
        {(loading || error) && <p>{loading ? "...טוען" : error}</p>}
        <input type="text" value={search} ref={searchRef} placeholder="חיפוש מתכון (באנגלית)" onChange={handleSearch}/>
        <ul>
            {filtered.map(r => <li key={r.id}><Link to={`/recipes/${r.id}`}>{r.name}</Link></li>)}
        </ul>
        {!(loading || error || filtered.length!=0)&&<p>לא נמצאו מתכונים</p>}
    </div >
}
export default RecipesList;

        'string.empty': 'אימייל הוא שדה חובה',
        'string.email':'כתובת האימייל אינה תקינה'
    }),
    password:Joi.string().min(6).required().messages({
        'string.empty': 'סיסמה היא שדה חובה',
        'string.min':'הסיסמה חייבת להיות באורך של 6 תווים לפחות'
    })
})
export default schema;
